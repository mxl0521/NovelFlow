## 使用边界

- 目前后台任务在单个 Python 进程内存中；部署、重启会丢失进行中的任务。适用于一个 web dyno、一个 API 进程；多 dyno 或进程需要 Redis 等共享持久任务队列，不能仅靠增加 worker 参数扩容。
- 小说持久化仍依赖原存储方式。Heroku 本地 SQLite/JSON 文件属于临时磁盘；需要使用已有 Supabase 云存储保护重启后的数据。
- 普通保存本身不调用模型，但正文变化后自动同步资料会消耗 token。数据库仍保存作品快照；“数据库读取全文”与“把全文发送给模型计费”是两件事。本次减少索引重建和资料输入，并未把整套快照存储迁移为按章节保存。
- 中转站失效、Key 权限/额度、真实上游超时和 Heroku 资源不足仍可能导致失败；不能承诺所有模型请求都成功。
